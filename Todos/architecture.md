## 数据流图

### 1. 读取日记流程

```
用户点击日期
    ↓
DayEditorModal 打开
    ↓
Editor 组件加载
    ↓
调用 GET /api/day?date=2025-11-16
    ↓
Prisma 查询 DayMeta
    ↓
返回 Markdown 内容
    ↓
BlockNote 解析 Markdown
    ↓
显示在编辑器中
```

### 2. 保存日记流程

```
用户编辑内容
    ↓
点击 Save 按钮
    ↓
BlockNote → Markdown
    ↓
┌───────────────────────────────┐
│ 1. POST /api/day              │
│    - 保存 Markdown 到 DayMeta │
└───────────────────────────────┘
    ↓
┌───────────────────────────────┐
│ 2. POST /api/analytic         │
│    - 发送 Markdown 到 AI      │
│    - AI 返回 JSON 数据        │
│    - 保存到 DayStruct         │
└───────────────────────────────┘
    ↓
Modal 关闭
    ↓
MonthView 刷新
    ↓
调用 GET /api/month?year=2025&month=11
    ↓
Prisma 查询当月所有 DayMeta + DayStruct
    ↓
渲染日历,显示可视化数据
```

### 3. AI 分析流程

```
接收 Markdown
    ↓
构建 Prompt:
┌────────────────────────────────────────┐
│ "你是生活记录分析助手..."              │
│ Markdown 内容: [用户的日记]            │
│ 请提取:                                │
│ - 餐饮完成度                           │
│ - 运动统计                             │
│ - 心情数据                             │
│ - 充实度评分                           │
│ 返回格式: JSON                         │
└────────────────────────────────────────┘
    ↓
调用 OpenRouter API
(模型: GLM-4.5-air)
    ↓
AI 返回 JSON:
{
  "breakfastTotal": 2,
  "breakfastCompleted": 1,
  ...
  "enrichmentScore": 0.65
}
    ↓
验证和清洗数据
    ↓
Upsert 到 DayStruct 表
```

## API 端点详情

### GET /api/day
**参数**: `date` (ISO 日期字符串)
**返回**: `{ dayMeta: { id, date, markdown, struct } }`
**用途**: 加载指定日期的日记

### POST /api/day
**参数**: `{ date, markdown }`
**返回**: `{ dayMeta: { id, date, markdown } }`
**用途**: 创建或更新日记

### GET /api/month
**参数**: `year`, `month` (数字)
**返回**: `{ days: [{ id, date, markdown, struct }] }`
**用途**: 获取指定月份的所有日记

### POST /api/analytic
**参数**: `{ date, markdown }`
**返回**: `{ success: true, data: DayStruct }`
**用途**: AI 分析 Markdown 并保存结构化数据

## 技术选型理由

### Next.js 16 (App Router)
- 服务端渲染 (SSR)
- API 路由
- 文件系统路由
- 优化的构建性能 (Turbopack)

### Prisma ORM
- 类型安全
- 自动迁移
- 强大的查询 API
- PostgreSQL 支持

### BlockNote 编辑器
- Markdown 支持
- 富文本编辑
- 所见即所得
- 可扩展

### OpenRouter API
- 多模型支持
- 价格实惠
- 稳定的 API
- GLM-4.5-air 免费

### Tailwind CSS
- 实用优先
- 响应式设计
- 小体积
- 快速开发

## 安全考虑

1. **API 密钥保护**: 使用环境变量,不提交到 Git
2. **输入验证**: API 路由验证必需参数
3. **数据库安全**: Prisma 防止 SQL 注入
4. **错误处理**: 完善的 try-catch,不暴露内部错误

## 性能优化

1. **Lazy Loading**: Editor 组件懒加载
2. **数据缓存**: Prisma 查询优化
3. **索引优化**: date 字段添加索引
4. **静态生成**: 主页静态预渲染

## 可扩展性

1. **模块化设计**: 组件独立,易于扩展
2. **API 分离**: 业务逻辑与 UI 分离
3. **类型安全**: TypeScript 全栈类型定义
4. **数据库灵活**: Prisma Schema 易于修改
